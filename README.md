# Digital Calorie Calculator

A beautiful and modern React application to track your screen time and calculate your "digital calories" for better digital wellness.

## Features

- 📱 Track multiple digital activities (Social Media, Streaming, Gaming, etc.)
- ⏱️ Precise time tracking with hours, minutes, and seconds
- 🎯 Real-time calorie calculation
- 📊 Health status indicators (Excellent, Moderate, High)
- 💡 Personalized wellness recommendations
- 🎨 Beautiful gradient UI with Tailwind CSS
- 📱 Fully responsive design

## Setup Instructions

### Prerequisites
- Node.js (version 16 or higher)
- npm or yarn

### Installation

1. Navigate to the project directory:
```bash
cd digitalcalculator
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit the URL shown in the terminal (usually `http://localhost:5173`)

### Build for Production

To create a production build:
```bash
npm run build
```

To preview the production build:
```bash
npm run preview
```

## Technologies Used

- **React 18** - UI framework
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **Lucide React** - Beautiful icon library

## How to Use

1. Enter your daily screen time for each activity type
2. Use the hour, minute, and second inputs for precise tracking
3. View your total digital calories and health status in real-time
4. Check the "Moderate Digital Diet" recommendations
5. Follow the wellness tips for healthier screen habits
6. Click "Reset Calculator" to start over
